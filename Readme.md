# TIDAL - OCEAN EXPLORER - 

tidal is an  ocean related website to explore ocean depth built to present fascinatng facts about the deep sea through a clean website it build totally with html css and javascript only

## why i build this --

most educational sites about marine biology and oceans are either heavy and contains a lot of banners and i wanted to build it clean web spaces where visitor can explore deep sea mysteris , descover intresting oceans facts and understand marine ecosystem through visuals

becouse it is made up of html css and javascript so you just clone the repositry from terminal or powershell 

just paste this 

